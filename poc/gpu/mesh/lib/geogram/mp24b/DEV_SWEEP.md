# MP24b development sweep: choosing T (a development sweep, NOT an acceptance set; run on the M1 before the freeze)

Binary: `geogram_fidelity2` source of this directory built with `-DT_EXP=200 -DMUT_C0` (scale on, exact re-centring skipped, no refusal: every row goes through MP22 Geogram at c = 0 after the exact scale). Corpus: `dev/gen_dev_sweep.cpp` (310 pairs = 930 runs). Shapes: icosphere levels 1, 2, 3 (radius 1), level 3 radius 1.1, and a spiky level 2 (every third vertex doubled); all full mantissa. Offset vector o = s*(1, -0.625, 0.5), s = 2^(j+1), j = 0..30, so the bounding-box centre / largest-side ratio is about 0.87 * 2^j. Each shape x j is run as the mesh against itself (identical; exact expected volumes) and against the same mesh shifted by 0.125 r (rounded dyadic; point tests, topology, orientation by `mesh_compare`, 5000 points). Scorer: `score_fidelity2.py`. Results: `dev/dev_sweep_results.tsv`.

Smooth shapes (744 runs), FAIL per j (24 runs each): j = 0..16: 0; j = 17: 6; 18: 11; 19: 20; 20: 13; 21: 14; 22: 11; 23: 18; 24: 18; 25: 11; 26: 8; 27: 16; 28: 12; 29: 11; 30: 11. The failures are inverted results (negative volume) and wrong point classification, the MP25 defect B (plain-double chart volume). **First failure: nominal ratio 2^17, measured bbox-centre/largest-side = 112147 = 2^16.78** (level 3 radius 1.1, shifted, difference); the largest passing ratio below it is 2^16 (all 24 runs).

**T = 2^12**: the largest power of two not above the first measured failure divided by 2^4 (2^16.78 / 16 = 2^12.78). (The nominal grid point would give 2^13; the measured ratio and the integer exponent give 2^12, the more conservative.) `T_EXP 12` is in `geogram_fidelity2.cpp` and in the frozen hash.

Separate finding (not a magnitude effect, excluded from the threshold): the spiky shape shifted against itself fails at small ratios too (76 of 186 runs FAIL, 17 of them below ratio 2^12: j = 0 (2), 1 (3), 2 (3), 5 (3), 6 (2), 8 (3), 12 (1)): results with a zero-area or duplicated triangle or a few mis-classified sample points. That is a Geogram behaviour on near-coincident spiky geometry independent of coordinate magnitude (it occurs at j = 0), so it is not a property of the pipeline's scaling or centring; the acceptance families use smooth icospheres only and this exclusion is stated here, not hidden.
